Mission: Find yourself.

Client Mosaique Journeys

Uzbekistan-based travel agency organizing private journeys across Uzbekistan and Central Asia.

Audience European travelers

Primary focus on EU clients, especially French travelers seeking cultural depth and reliable local planning.

Project scope Landing page + admin panel

Premium public website concept with a simple operational dashboard for trips and inquiries.

Project Intent

The project positions Mosaique Journeys as a refined local travel specialist with international standards. The website is designed to build trust, communicate cultural expertise, and convert qualified visitors into private travel inquiries.

Brand system

Visual Identity Direction

The identity is warm, editorial, and culturally grounded. It avoids generic tour-operator styling and presents Uzbekistan and Central Asia as premium, human, and deeply personal destinations.

Color Palette

Deep Ink #181715 Primary text, premium contrast
Warm Ivory #F6F0E7 Page background, calm warmth
Olive Moss #394838 Trust, nature, primary actions
Silk Clay #9B553F Cultural accents and section labels
Muted Gold #C69A52 Heritage detail, luxury restraint
Desert Sand #E8DCCB Secondary background bands

Typography

Editorial headline Find yourself on the Silk Road

Georgia / Times-style serif for premium, travel editorial headlines.

Interface and body copy Clear planning, trusted guidance, cultural connection.

Inter / modern system sans-serif for readability, forms, navigation, and admin UI.

Brand Voice

  • Elegant, calm, and confident.
  • Specific about destinations, guides, comfort, and cultural access.
  • Written for European travelers who may be discovering Central Asia for the first time.
  • Premium without exaggerated luxury claims.

Delivered product

Website and Admin Panel

The current prototype establishes the visual direction, user journey, and core operational structure needed before production development.

Public Website

  • Full-screen premium travel hero.
  • Journey finder for destination, travel style, and season.
  • Featured journey cards for Uzbekistan and Central Asia routes.
  • Agency approach section explaining planning quality.
  • Inquiry form for lead generation.

Admin Panel

  • Dashboard overview for inquiries and active journeys.
  • Inquiry table with lead status tracking.
  • Featured package management concept.
  • Task list for day-to-day agency operations.
  • Clear path toward Supabase-backed data management.

Technical Direction

Current stage

Static responsive prototype running locally, suitable for design approval and content refinement.

Recommended production path

Next.js frontend with Supabase for inquiries, admin authentication, destinations, trip packages, and media.

Deployment options

Vercel + Supabase for fastest launch, or Hetzner for a self-hosted production setup when required.

Completion Notes and Next Steps

  1. Replace prototype imagery with owned Uzbekistan and Central Asia photography.
  2. Finalize English copy and prepare a high-quality French version.
  3. Connect Supabase data, authentication, inquiries, and media.
  4. Prepare production SEO, analytics, backups, and email delivery.
